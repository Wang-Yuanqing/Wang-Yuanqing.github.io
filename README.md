# Yuanqing Wang — Personal Academic Homepage

Live at **https://wang-yuanqing.github.io/** — Jekyll on GitHub Pages.

## Where things live

| What | File |
| --- | --- |
| All page content (About, News, Publications, Education, Experience) | `_pages/about.md` |
| Name, bio, avatar, email, CV link, social links | `_config.yml` |
| Sidebar nav | `_data/navigation.yml` |
| Styles | `assets/css/main.scss` |
| CV and thesis PDFs | `files/` |
| Publication figures | `images/publications/` |

## Run locally

```bash
bundle install
./run_server.sh   # or: bundle exec jekyll serve
```

Then open http://127.0.0.1:4000.
